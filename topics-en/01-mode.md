# 🔁 Mode

🌐 [Русская версия](../topics/01-mode.md)

**Mode** — the value that occurs most often in a dataset.

**Examples:**
- Set: 2, 3, 3, 5, 7 → mode = **3**.
- Set: 1, 2, 3, 4 → no mode (all values are unique).
- Set: 1, 1, 2, 2, 3 → two modes: **1 and 2** (bimodal distribution).

**Features:**
- Applicable to categorical data too (e.g., the most popular car color).
- In continuous data, the mode can be uninformative or absent.
- Useful for identifying the most frequent categories and distribution peaks.

**Key takeaway:** the mode is the only measure of central tendency applicable to categorical data.
