# Индекс: аналитика данных

Полный конспект по аналитике данных разбит на тематические файлы в папке `topics/`. Многоплановые темы устроены так:

- **Обзорная страница (хаб)** — сохранила исходное имя файла: содержит таблицу навигации по подтемам, сравнительную таблицу и общее резюме.
- **Тематические файлы** — по одному на каждую подтему: подробное содержание, ссылка «← К обзору» и связанные темы.
- **Одноплановые темы** — один файл без разбиения.
