# 🌊 Скользящие средние
🌐 [English version](../topics-en/27-moving-averages.md)

**Скользящее среднее (Moving Average)** — метод сглаживания временного ряда: в каждой точке берётся среднее за окно предыдущих k значений.

**Формула (простое скользящее среднее):**
$$
\text{MA}_t = \frac{x_t + x_{t-1} + \ldots + x_{t-k+1}}{k}
$$
где k — размер окна.

**Пример:**
Выручка по дням: [10, 12, 11, 14, 13].
Скользящее среднее с окном 3 для t=3: (10+12+11)/3 = 11; для t=4: (12+11+14)/3 ≈ 12.3.

**Виды:**
- **Простое (SMA)** — равные веса.
- **Экспоненциальное (EMA)** — больший вес у последних значений (учёт, что прошлое влияет меньше).

**Зачем:**
- Убрать «шум» и увидеть тренд (см. [Тренды](06-trends.md)).
- Снизить влияние отдельных выбросов.
- Основа для сигналов в трейдинге и мониторинге аномалий.

**Как выбирать окно k:**
- Маленькое окно → близко к исходным данным, больше шума.
- Большое окно → более гладкая линия, но «задержка» реакции на изменения.
- Для месячных данных часто берут окно 12 (месяцев), для дневных — 7 (недельный цикл).

**Инсайт:** скользящее среднее «задерживается» на поворотных точках (сглаживание вида «догоняет»). Не полагайтесь только на него для поиска переломов — комбинируйте с другой техникой (декомпозиция).
