# 🛒 Конверсионная воронка
🌐 [English version](../topics-en/09-conversion-funnel.md)

**Конверсионная воронка** — описание пути пользователя к целевому действию в виде последовательности этапов. На каждом шаге часть пользователей «отпадает», поэтому форма превращается в воронку.

**Классический пример (e-commerce):**
1. Посещение сайта
2. Просмотр товара
3. Добавление в корзину
4. Оформление заказа
5. Оплата

**Основные метрики воронки:**
- **Конверсия** на каждом этапе: доля пользователей, перешедших со этапа i на этап i+1:
$$
\text{Конверсия этапа} = \frac{\text{число пользователей на этапе i+1}}{\text{число пользователей на этапе i}} \times 100\%
$$
- **Общая конверсия** — доля пользователей, прошедших всю воронку целиком (от первого до последнего шага).

**Пример:**
Сайт посещают 10 000 человек. В корзину добавили — 2 000. Купили — 300.
- Конверсия «к корзине» = 2000/10000 = 20%.
- Конверсия «в покупку из корзины» = 300/2000 = 15%.
- Общая конверсия = 300/10000 = 3%.

**Зачем анализировать воронку:**
- Найти этап с самым большим процентом «отвала» — он и есть узкое место.

**Методы работы с воронкой:**
- A/B-тестирование отдельных этапов (например, упрощение формы заказа).
- Анализ сегментов (мобильные vs десктоп, новые vs старые).
- Анализ времени между шагами (как в [Анализе времени выполнения теста](05-test-duration.md)).

**Ошибки:**
- Считать воронку «с момента входа» — не все пользователи входят через первый шаг.
- Игнорировать, что один пользователь может проходить воронку в несколько заходов.
- Смешивать разные сегменты трафика.

**Инсайт:** воронка показывает, где теряются пользователи, но не почему. Для выяснения причин нужны качественные данные (тепловые карты, записи сессий, опросы) и эксперименты.
