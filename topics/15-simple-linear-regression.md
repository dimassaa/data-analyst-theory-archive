# 📈 Простая линейная регрессия
🌐 [English version](../topics-en/15-simple-linear-regression.md)

**Простая линейная регрессия** — модель, описывающая связь одной зависимой переменной $ y $ с одним фактором $ x $ с помощью прямой линии.

**Формула:**
$$
\hat{y} = b_0 + b_1 x
$$
- $ b_0 $ — пересечение (значение $ \hat{y} $ при $ x = 0 $),
- $ b_1 $ — коэффициент наклона (среднее изменение $ y $ при росте $ x $ на 1),
- $ \hat{y} $ — прогнозируемое значение.

**Пример:**
$$
\text{выручка} = 50 + 2 \cdot \text{число рекламных показов (тыс.)}
$$
При 0 показов выручка ≈ 50 тыс.; каждый дополнительный 1000 показов добавляет ≈ 2 тыс. выручки.

**Типичные задачи:**
- Прогнозирование (продажи по сезону, спрос по ценам).
- Оценка влияния фактора (насколько растёт метрика при изменении входной величины).

**Как подбирают линию:**
Коэффициенты подбираются методом наименьших квадратов — прямая, при которой сумма квадратов вертикальных отклонений точек от линии минимальна (см. [МНК/OLS](15-ols.md)).

**Оценка качества:**
- **R²** — доля объяснённой вариации $ y $. R² = 0.8 → 80% разброса объясняется моделью.
- **Анализ остатков**: остатки должны быть разбросаны случайно без чётких паттернов; паттерны означают нелинейность связи или пропущенный фактор.

**Предпосылки (для корректных выводов):**
- Линейность связи.
- Независимость наблюдений.
- Остатки нормально распределены и имеют постоянную дисперсию (гомоскедастичность).

**Инсайт:** интерпретируйте $ b_1 $ как «средний эффект» фактора, но помните: корреляция ≠ причинность. Связь может быть искажена третьей переменной, которая влияет на оба фактора.
