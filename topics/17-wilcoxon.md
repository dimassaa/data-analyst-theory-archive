# 🔗 Тест Уилкоксона (signed-rank)
🌐 [English version](../topics-en/17-wilcoxon.md)

**Тест Уилкоксона** (Wilcoxon signed-rank) — непараметрический критерий для проверки гипотезы о том, что медиана **разностей** парных наблюдений равна нулю (т.е. различий нет). Применяется для ** зависимых (парных) выборок**.

**Альтернатива параметрическому:** парный t-тест.

**Идея:** вычисляются разности пар $ d_i = x_i - y_i $, эти разности упорядочиваются по модулю (ранжируются) и считаются сумма положительных и отрицательных рангов. Чем сильнее смещение, тем меньше p-value.

**Пример:**
До и после изменения дизайна измеряется время выполнения задачи у одних и тех же пользователей. Если распределение разностей не нормально — вместо парного t-теста применяем тест Уилкоксона.

**Когда использовать:**
- Парные данные (до/после, лево/право, два прибора).
- Разности не распределены нормально.
- Есть выбросы.

**Ограничения:**
- Использует только **ранжированные** данные — не учитывает magnitude (величину) различий.
- Не работает, если разность равна 0 более чем в ~5% пар (нужно удалять или использовать специальные модификации).

**Инсайт:** для парных данных — это «непараметрический парный t-тест». Если в ваших данных есть выбросы в разностях, Уилкоксон надёжнее.
