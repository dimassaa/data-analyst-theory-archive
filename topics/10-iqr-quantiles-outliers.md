# 📊 Квартили, IQR и выбросы
🌐 [English version](../topics-en/10-iqr-quantiles-outliers.md)

Квартили, межквартильный размах (IQR) и выбросы — инструменты описания распределения данных и обнаружения аномалий. Эти метрики **устойчивы к выбросам** (в отличие от среднего и стандартного отклонения) и поэтому особенно полезны при реальных данных, которые почти всегда содержат аномалии.

## 📊 Сравнительная таблица

| Понятие | Что показывает | Формула / правило | Устойчивость к выбросам |
|---------|----------------|-------------------|------------------------|
| **Квантили** | Значение, ниже которого p% данных | Сортировка + интерполяция | ✓ Высокая |
| **Квартили (Q1, Q2, Q3)** | 25%, 50%, 75% квантили | Аналогично | ✓ Высокая |
| **IQR** | Разброс серединных 50% | $ Q3 - Q1 $ | ✓ Высокая |
| **Box plot** | Визуал распределения | Q1, Q3, усы, выбросы | ✓ Визуально |
| **Выбросы** | Аномальные значения | За пределами Q1-1.5·IQR или Q3+1.5·IQR | Зависит от правила |

**Как связаны:**
1. Сначала вычисляются **квартили** (Q1, Q2=медиана, Q3).
2. По квартилям рассчитывается **IQR** (размах серединных 50%).
3. IQR используется для построения **box plot** и обнаружения **выбросов**.

---

## ✅ Резюме

- Квартили дают полную картину распределения без искажения выбросами.
- IQR — устойчивая альтернатива стандартному отклонению для оценки разброса.
- Box plot — наглядный инструмент для быстрого сравнения распределений нескольких групп.
- Выбросы — не всегда ошибки: иногда это важнейшие данные (мошенничество, сбои, суперпользователи).
