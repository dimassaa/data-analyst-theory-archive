# 🔄 Ковариация и ANOVA
🌐 [English version](../topics-en/16-covariance-and-anova.md)

**Ковариация** измеряет совместную вариацию двух переменных, а **ANOVA (дисперсионный анализ)** сравнивает средние нескольких групп через анализ дисперсий. Оба метода — часть статистического инструментария для изучения связей и различий.

## 📊 Сравнительная таблица

| Аспект | Ковариация | ANOVA |
|--------|-----------|-------|
| Вопрос | Как изменяются вместе две переменные? | Различаются ли средние у нескольких групп? |
| Тип данных | $ n $ пар (x, y) — обе количественные | Групповая (категориальная) + количественная |
| Число переменных | 2 | Фактор (группы) + 1 непрерывная |
| Результат | Число (знак + / −) | F-статистика с p-value |
| Связь с корреляцией | Нормированная ковариация = корреляция Пирсона | F-статистика сравнивает дисперсии |

**Как связаны:**
- Ковариация → нормировка → коэффициент корреляции Пирсона (см. [Корреляция Пирсона](07-pearson-correlation.md)).
- ANOVA сравнивает **рассияние между группами** с **рассеянием внутри групп**: F = между-групповая дисперсия / внутри-групповая.

---

## ✅ Резюме

- **Ковариация**: знак показывает направление связи (прямая/обратная), но величина зависит от масштаба данных — поэтому удобнее пользоваться корреляцией.
- **ANOVA**: расширение t-критерия на 3+ групп; показывает, есть ли хоть одно значимое отличие, не указывая какое именно (нужны пост-хок тесты).
