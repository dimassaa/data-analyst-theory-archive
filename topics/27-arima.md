# 🤖 ARIMA
🌐 [English version](../topics-en/27-arima.md)

**ARIMA (AutoRegressive Integrated Moving Average)** — классическая статистическая модель для прогнозирования временных рядов. Сочетает автокорреляцию, интегрирование (разности) и скользящее среднее.

**Расшифровка:**
- **AR** (авторегрессия): будущее значение зависит от предыдущих значений.
- **I** (интегрирование): ряд приводится к стационарному виду разностями.
- **MA** (скользящее среднее): учитывает прошлые ошибки прогноза.

**Обозначение ARIMA(p, d, q):**
- **p** — порядок авторегрессии (число лагов y, используемых при прогнозе).
- **d** — порядок разностей (сколько раз брали разности для стационарности).
- **q** — порядок скользящего среднего ошибок.

**Пример модели:** ARIMA(1,1,1) — один лаг авторегрессии, одна разность для стационарности, один лаг ошибки.

**Как выбрать параметры:**
- Данные (p, d, q) подбираются с помощью ACF/PACF графиков и информационных критериев (AIC/BIC).
- Часто используют автоматический подбор (auto-ARIMA в библиотеках).

**Предпосылка — стационарность:**
Ряд должен быть стационарным (среднее и дисперсия постоянны во времени). Нестационарность устраняется разностями (часть I) или трансформацией (логарифмы).

**Ограничения:**
- Линейная модель — плохо отражает нелинейные закономерности.
- Не справляется с нестандартными сезонностями без расширений (SARIMA для сезонности).
- Требует достаточной длины истории.

**Инсайт:** ARIMA — хороший «стартовый» бенчмарк для прогнозирования [и машиннообученческие модели (LSTM, XGBoost) сравнивают именно с ним]. Для сезонных бизнес-метрик сначала смотрите на декомпозицию (см. [Декомпозиция](27-decomposition.md)), потом примените SARIMA.
