# 🔀 Тест Манна–Уитни (U-тест)
🌐 [English version](../topics-en/17-mann-whitney.md)

**Тест Манна–Уитни** (Mann–Whitney U) — непараметрический критерий для проверки гипотезы о том, что две **независимые** выборки получены из одного распределения, или что распределение одной выборки сдвинуто относительно другой.

**Альтернатива параметрическому:** t-тест для независимых выборок.

**Идея:** заменяем значения рангами (порядковыми номерами) и сравниваем средние ранги групп. Не предполагает нормальности распределения.

**Формула статистики U (концептуально):**
U показывает, как часто элементы одной группы превосходят элементы другой. Чем ближе U к 0 (маленький), тем сильнее различия распределений.

**Пример:**
Тестируем два дизайна интерфейса по времени выполнения задачи. Данные асимметричны и содержат выбросы. Тест Манна–Уитни проверяет, есть ли значимая разница в распределениях, не опираясь на нормальность.

**Когда использовать:**
- Данные **не нормально** распределены (выбросы, сильная асимметрия).
- Данные **порядковые** (рейтинги, оценки, ранги).
- Маленькая выборка, когда t-тест ненадёжен.

**Ограничения:**
- Не даёт оценку **размера эффекта** напрямую (нужно считать отдельно).
- Менее мощен, чем t-тест, если нормальность действительно выполняется (цена свободы от предпосылок).

**Инсайт:** U-тест непараметрический аналог t-теста для независимых групп. Для зависимых (парных) данных используйте тест Уилкоксона.
