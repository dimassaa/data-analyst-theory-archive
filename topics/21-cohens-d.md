# 📐 Коэффициент Коэна (Cohen's d)
🌐 [English version](../topics-en/21-cohens-d.md)

**Cohen's d** — стандартизированный размер эффекта для разницы между двумя средними. Показывает, на сколько стандартных отклонений различаются средние группы.

**Формула:**
$$
d = \frac{\bar{x}_1 - \bar{x}_2}{s_p}
$$
где $ \bar{x}_1, \bar{x}_2 $ — средние групп, $ s_p $ — объединённое (pooled) стандартное отклонение:
$$
s_p = \sqrt{\frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}}
$$

**Пример:**
Контроль: средняя конверсия 10%, sd=2%. Тест: 12%, sd=2%. n равные.
d = (12 - 10) / 2 = **1.0** → сильный эффект (разница в одно стандартное отклонение).

**Эмпирические границы интерпретации (по Коэну):**
| |d| | Интерпретация |
|-----|---------------|
| 0.0–0.2 | Небольшой эффект (маленький) |
| 0.2–0.5 | Небольшой/умеренный |
| 0.5–0.8 | Средний эффект |
| 0.8+ | Большой эффект |

**Зачем стандартизация:**
- d — безразмерная величина, поэтому можно сравнивать эффекты из разных исследований (метаанализ).
- Не зависит от единиц измерения (рубли, секунды, проценты — всё переводится в «стандартные отклонения»).

**Ограничения:**
- Чувствителен к выбросам (они искажают sd).
- Не заменяет интервалы неопределённости — полезно приводить доверительный интервал для d.

**Инсайт:** Cohen's d — «общий язык» для размера эффекта. В A/B-тестах, научных публикациях и отчётах d позволяет быстро понять, насколько большое различие, независимо от изначальных единиц.
