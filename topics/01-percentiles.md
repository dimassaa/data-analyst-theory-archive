# 📈 Перцентили
🌐 [English version](../topics-en/01-percentiles.md)

**Перцентиль** — значение, ниже которого падает определённый процент наблюдений. Например, 90-й перцентиль — это значение, ниже которого находятся 90% данных.

**Частные случаи:**
- **Медиана** = 50-й перцентиль.
- **Квартили**:
  - 1-й квартиль (Q1) = 25-й перцентиль,
  - 2-й квартиль (Q2) = медиана,
  - 3-й квартиль (Q3) = 75-й перцентиль.
- **Децили** (каждые 10%) и др.

**Как вычислить:**
1. Отсортировать данные по возрастанию.
2. Найти ранг: $ \text{ранг} = \frac{p}{100} \times (n+1) $, где p — перцентиль, n — число наблюдений.
3. Если ранг целый — берём соответствующее значение, если дробный — интерполируем между соседними значениями.

**Пример:**
Данные: 2, 4, 6, 8, 10, 12, 14.
25-й перцентиль: ранг = 25/100 × 8 = 2 → 2-е значение = **4**.
90-й перцентиль: ранг = 90/100 × 8 = 7.2 → интерполяция между 7-м (14) и 8-м (нет) — берём 14.

**Особенности:**
- Устойчивы к выбросам, дают полную картину распределения.
- Широко используются для сравнения (например, «ваш доход выше 80% населения»).
- Основа для построения box plot (ящика с усами).

**Инсайт:** перцентили — самый надёжный способ описать распределение при выбросах и асимметрии.
