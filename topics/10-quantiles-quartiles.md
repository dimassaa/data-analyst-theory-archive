# 📈 Квантили и квартили
🌐 [English version](../topics-en/10-quantiles-quartiles.md)

**Квантиль** — значение, ниже которого находится заданная доля наблюдений.

**Частные случаи квантилей:**
- **Медиана** = 50-й квантиль (Q2).
- **Квартили**: Q1 = 25-й квантиль, Q3 = 75-й квантиль.
- **Децили**: 10-й, 20-й, ..., 90-й квантили.
- **Перцентили**: то же, что и квантили, выраженные в процентах.

**Как вычислить квартиль Q1 (25-й квантиль):**
1. Отсортировать данные по возрастанию.
2. Найти позицию: $ \text{позиция} = 0.25 \times (n+1) $.
3. Если позиция целая — берём значение, если дробная — интерполируем.

**Пример:**
Данные: 2, 4, 6, 8, 10, 12, 14.
- Q1: позиция = 0.25 × 8 = 2 → 2-е значение = **4**.
- Q2 (медиана): позиция = 0.5 × 8 = 4 → 4-е значение = **8**.
- Q3: позиция = 0.75 × 8 = 6 → 6-е значение = **12**.

**Квартили делят данные на четыре равные части:**
- 25% данных < Q1,
- 50% данных < Q2 (медиана),
- 75% данных < Q3,
- 100% данных < Q3.

**Зачем нужны квартили:**
- Описывают форму распределения без искажения выбросами.
- Лежат в основе расчёта IQR и box plot.
- Дают быструю интуицию: если Q1=10, Q3=50, то серединные 50% данных находятся в диапазоне 10–50.

**Инсайт:** квартили дают полную картину распределения даже при наличии выбросов, в отличие от среднего и стандартного отклонения, которые могут быть «сдвинуты» аномальными значениями.
