# 🧩 Кластеризация и PCA
🌐 [English version](../topics-en/25-clustering-and-pca.md)

**Кластеризация** — метод обучения без учителя, который группирует похожие объекты без заранее заданных меток. **PCA (метод главных компонент)** — метод снижения размерности, который упрощает данные, сохраняя максимум вариации. Оба инструмента — стержень разведочного анализа и основа сегментации.

---

## 📊 Сравнительная таблица

| Аспект | K-means | PCA |
|--------|---------|-----|
| Тип задачи | Кластеризация (без учителя) | Снижение размерности |
| Вход | Набор объектов с признаками | Набор объектов с признаками |
| Выход | Метки кластеров для объектов | Новые координаты (главные компоненты) |
| Цель | Найти скрытые группы | Упростить данные, убрать корреляции |
| Подход | Минимизация расстояний до центров кластеров | Собственные векторы матрицы ковариаций |
| Связка | Часто применяется после PCA | Часто применяется перед кластеризацией |

---

## ⏭️ Распространённый конвейер

```
Исходные данные (много признаков)
        │
        ▼
   PCA (снижение размерности, удаление лишнего шума)
        │
        ▼
   K-means (кластеризация в новом пространстве)
        │
        ▼
   Интерпретация сегментов → бизнес-действия
```

Понимание линейной алгебры (см. [Линейная алгебра](12-linear-algebra.md)) сильно облегчает понимание обоих методов.

---

## ✅ Резюме

- **PCA** помогает сжимать данные, визуализировать высокие размерности и «чистить» признаки от мультиколлинеарности.
- **K-means** позволяет находить сегменты пользователей/объектов и интерпретировать их.
