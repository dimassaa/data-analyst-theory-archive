# 🔁 Мода
🌐 [English version](../topics-en/01-mode.md)

**Мода** — значение, которое встречается в наборе данных чаще всего.

**Примеры:**
- Набор: 2, 3, 3, 5, 7 → мода = **3**.
- Набор: 1, 2, 3, 4 → моды нет (все значения уникальны).
- Набор: 1, 1, 2, 2, 3 → две моды: **1 и 2** (бимодальное распределение).

**Особенности:**
- Применима и к категориальным данным (например, самый популярный цвет автомобиля).
- В непрерывных данных мода может быть неинформативной или отсутствовать.
- Полезна для выявления наиболее частых категорий, пиков распределения.

**Инсайт:** мода — единственная мера центральной тенденции, применимая к категориальным данным.
