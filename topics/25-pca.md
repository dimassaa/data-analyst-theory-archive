# 📉 PCA (метод главных компонент)
🌐 [English version](../topics-en/25-pca.md)

**PCA (Principal Component Analysis)** — метод снижения размерности: находит новые ортогональные направления (главные компоненты), вдоль которых данные имеют максимальный разброс. Поворачивает данные в новые координаты и позволяет отбросить «малозначимые» направления.

**Идея:**
1. Данные центрируются (вычитается среднее).
2. Строится **матрица ковариаций** признаков (см. [Ковариация](16-covariance.md)).
3. Находятся её **собственные векторы** (главные компоненты) и **собственные числа** (доля объяснённой вариации).
4. Данные проецируются на первые несколько компонент.

**Пример:**
Датасет с 100 признаками. Первые 5 главных компонент объясняют 85% вариации → можно работать с 5 «сжатыми» признаками вместо 100. Это ускоряет модели, уменьшает переобучение.

**Что даёт PCA:**
- **Снижение размерности**: меньше признаков — меньше шума и переобучения.
- **Визуализация**: 2–3 первых компонент позволяют нарисовать данные высокой размерности на плоскости.
- **Устранение мультиколлинеарности**: новые признаки ортогональны (некоррелированы).

**Интерпретация:**
- Каждая компонента — линейная комбинация исходных признаков.
- **Loadings (нагрузки)** показывают, какие исходные признаки вносят наибольший вклад в компоненту — можно «читать» смысл компоненты.

**Ограничения:**
- Компоненты сложно интерпретировать для бизнеса («что значит главная компонента #3?»).
- PCA предполагает **линейные** структуры.
- Требует **стандартизации** признаков, иначе признаки с большой дисперсией доминируют.

**Инсайт:** PCA часто используют **в паре** с кластеризацией: сначала снижают размерность, потом кластеризуют (см. [K-means](25-k-means.md)). Для продуктовой сегментации PCA помогает выделить «латентные факторы» поведения пользователей.
