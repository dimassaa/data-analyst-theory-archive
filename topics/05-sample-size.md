# 🧮 Размер выборки для A/B-теста
🌐 [English version](../topics-en/05-sample-size.md)

Размер выборки — число пользователей в каждой группе, необходимое, чтобы с заданной уверенностью обнаружить эффект выбранного размера.

**От чего зависит:**
- **Уровень значимости (α)** — меньше α → нужна большая выборка.
- **Мощность (1-β)** — больше мощность → нужна большая выборка.
- **MDE (минимальный детектируемый эффект)** — меньше эффект, который нужно поймать → нужна большая выборка.
- **Вариация метрики (σ)** — больше разброс → нужна большая выборка.

**Формула для сравнения долей (конверсий):**
$$
n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2 \cdot (p_1(1-p_1) + p_2(1-p_2))}{(p_2 - p_1)^2}
$$
где $ p_1 $, $ p_2 $ — базовый и ожидаемый уровень конверсии.

**Пример:**
Базовая конверсия 10%, хотим обнаружить улучшение до 12% (рост на 20% относительных).
При α=0.05 и мощности 80% (z-значения 1.96 и 0.84):
числитель = (1.96+0.84)² × (0.1×0.9 + 0.12×0.88) ≈ 7.84 × 0.1956 ≈ 1.53
знаменатель = (0.02)² = 0.0004
n ≈ 1.53 / 0.0004 ≈ **3825 пользователей на группу** (≈ 7650 всего).

Иногда считают совокупный размер выборки для двух групп, поэтому важно понимать, что n в формуле — это обычно размер **каждой** группы.

**Инсайт:** чем меньше выброс, тем большая выборка нужна. Если MDE очень маленький (например, +1%), размер выборки может оказаться практически недостижимым — надо подумать, действительно ли бизнесу важен такой маленький прирост.
