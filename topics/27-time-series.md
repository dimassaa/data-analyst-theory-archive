# 📈 Временные ряды: скользящие средние, декомпозиция, ARIMA
🌐 [English version](../topics-en/27-time-series.md)

**Временной ряд** — последовательность наблюдений, упорядоченных во времени (выручка по дням, продажи по неделям, трафик по часам). Анализ временных рядов — основа прогнозирования и мониторинга аномалий.

## 📊 Сравнительная таблица

| Метод | Тип | Назначение | Сложность |
|-------|-----|-----------|-----------|
| **Скользящее среднее** | Сглаживание | Выявить тренд, убрать шум | Низкая |
| **Декомпозиция** | Разложение | Разделить на тренд + сезонность + остаток | Средняя |
| **ARIMA** | Модель прогнозирования | Прогноз будущих значений | Высокая |

**Ключевые компоненты любого ряда:**
- **Тренд** — долгосрочное направление.
- **Сезонность** — повторяющиеся паттерны (недели, месяцы, праздники) (см. [Тренды](06-trends.md)).
- **Остаток (шум)** — нерегулярная часть.

---

## ✅ Резюме

- Скользящие средние — первый инструмент для «чистки» ряда от шума.
- Декомпозиция помогает понять структуру ряда до моделирования.
- ARIMA — классический метод прогноза, но требует подготовки данных и проверки стационарности.
