# 📊 t-критерий Стьюдента
🌐 [English version](../topics-en/04-t-test.md)

**t-критерий** используется для сравнения средних значений, когда стандартное отклонение генеральной совокупности **неизвестно** и оценивается по выборке.

**Виды t-критерия:**
1. **Одновыборочный** — сравнение среднего выборки с известным значением.
2. **Для независимых выборок** — сравнение средних двух несвязанных групп.
3. **Парный (зависимый)** — сравнение средних двух связанных измерений (например, до и после лечения).

**Формула для независимых выборок (с равными дисперсиями):**
$$
t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}
$$
где $ s_p $ — объединённое стандартное отклонение.

**Степени свободы:** $ df = n_1 + n_2 - 2 $.

**Условия применения:**
- Данные приблизительно нормально распределены (особенно при малых выборках).
- Для независимых выборок — независимость наблюдений.

**Пример:**
Тестируем новую версию сайта: контрольная группа (n₁=100, средняя конверсия 10%, s₁=2%) и тестовая (n₂=100, средняя 12%, s₂=2%).
H₀: μ₁ = μ₂.
Вычисляем t ≈ 7.07, p-value < 0.001 → отвергаем H₀, разница статистически значима.

**Инсайт:** t-критерий устойчив к умеренным отклонениям от нормальности при достаточно больших выборках (n > 30). При сильной асимметрии лучше использовать непараметрические аналоги (например, тест Манна–Уитни).
