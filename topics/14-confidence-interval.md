# 📏 Доверительный интервал (ДИ)
🌐 [English version](../topics-en/14-confidence-interval.md)

**Доверительный интервал** — интервал значений, который с заданной вероятностью (уровнем доверия, обычно 95%) накрывает истинное значение параметра генеральной совокупности.

**Формула 95% ДИ для среднего (большая выборка):**
$$
\bar{x} \pm 1.96 \cdot \text{SE} = \bar{x} \pm 1.96 \cdot \frac{s}{\sqrt{n}}
$$
При малых выборках вместо z=1.96 берётся t-значение Стьюдента с df = n-1.

**Пример:**
Средний чек 500 руб., SE = 15.
95% ДИ = (500 - 1.96×15; 500 + 1.96×15) = (500 - 29.4; 500 + 29.4) = **(470.6; 529.4)** руб.

**Правильная трактовка:**
- «Если многократно повторять эксперимент и каждый раз строить 95% ДИ, то в 95% случаев интервал накроет истинное среднее».
- **Нельзя** говорить: «вероятность того, что истинное среднее лежит в интервале, равна 95%» (истинное значение фиксировано, интервал случаен).

**Как изменяется ДИ:**
- Больше выборка → уже интервал.
- Выше уровень доверия (99% vs 95%) → шире интервал.
- Больше разброс → шире интервал.

**Применение в аналитике:**
- **A/B-тесты**: если 95% ДИ прироста конверсии не содержит 0 → эффект значим. Если интервал содержит 0 → вывод нельзя сделать.
- **Отчёты**: вместо «средняя конверсия 3%» правильно писать «95% ДИ: 2.7%–3.4%».
- Оценка точности прогнозов моделей.

**Инсайт:** ДИ даёт больше информации, чем одна цифра: он показывает и оценку, и степень её достоверности. В продуктовых отчётах всегда указывайте ДИ для ключевых метрик — это защита от излишней уверенности.
