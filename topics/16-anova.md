# 📊 ANOVA (дисперсионный анализ)
🌐 [English version](../topics-en/16-anova.md)

**ANOVA (Analysis of Variance)** — статистический метод для проверки, различаются ли **средние трёх и более групп** (категориальный фактор → непрерывная переменная). Расширяет t-критерий, который работает только для двух групп.

**Идея:**
Разбить общую изменчивость данных на две части:
1. **Межгрупповая вариация** (между средними групп) — сюда входит эффект фактора.
2. **Внутригрупповая вариация** (внутри групп, «шум») — естественный разброс.

**F-статистика:**
$$
F = \frac{\text{межгрупповая дисперсия}}{\text{внутригрупповая дисперсия}}
$$
Большое F → средние групп различаются сильнее, чем можно объяснить случайностью.

**Пример:**
Сравниваем средний чек по трём каналам привлечения: контекст, таргет, SEO.
H₀: средние равны. F-тест с p-value < 0.05 → отвергаем H₀ → хотя бы один канал отличается.

**Предпосылки:**
- Наблюдения независимы.
- Данные в группах приблизительно нормальны.
- Дисперсии групп приблизительно равны (гомоскедастичность).

**Ограничение:**
ANOVA говорит «есть различие», но **не говорит, между какими группами**. Для этого нужны **пост-хок тесты** (Тьюки, Бонферрони) — они сравнивают пары групп с поправкой на множественность (см. [Множественная проверка гипотез](17-multiple-hypothesis-testing.md)).

**Инсайт:** если групп две — можно использовать t-критерий, для 3+ групп — ANOVA. Не ищите различия множеством t-критериев: это увеличивает риск ложноположительных выводов из-за множественности сравнений.
