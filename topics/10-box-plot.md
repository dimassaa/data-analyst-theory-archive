# 📦 Ящик с усами (Box plot)
🌐 [English version](../topics-en/10-box-plot.md)

**Box plot (ящик с усами)** — графическое представление распределения, показывающее ключевые статистики: медиану, квартили, размах и выбросы.

**Элементы box plot:**
- **Ящик**: от Q1 до Q3 (содержит 50% данных).
- **Линия в ящике**: медиана (Q2).
- **Усы**: простираются до последнего значения, не превышающего Q3 + 1.5 × IQR (верхний «ус») и не меньшего Q1 - 1.5 × IQR (нижний «ус»).
- **Точки за усами**: выбросы.

**Пример визуализации ( текстовое представление):**
```
         ┌─────────┐
  |──────┤    |    ├──────|    ●   ●
         └─────────┘
  ←─ ус ─→ ←─ ящик ─→ ←─ ус ─→   выбросы
```

**Зачем нужен box plot:**
- Одним взглядом оценить **центр**, **разброс**, **симметрию** и **наличие выбросов**.
- Удобно сравнивать распределения нескольких групп (рядом стоящие box plot'ы).
- Более информативен, чем просто среднее + стандартное отклонение.

**Сравнение распределений:**
- Широкий ящик → большой разброс данных.
- Медиана смещена к краю ящика → асимметрия.
- Много точек за усами → данные содержат выбросы.

**Инсайт:** box plot — лучший инструмент для быстрого сравнения нескольких групп (например, конверсии по каналам). Он одновременно показывает и центр, и разброс, и аномалии.
