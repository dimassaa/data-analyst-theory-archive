# 📊 Ранговая корреляция Спирмена
🌐 [English version](../topics-en/07-spearman-correlation.md)

**Коэффициент корреляции Спирмена (ρ)** — мера **монотонной** связи между двумя переменными, вычисляемая по **рангам**, а не по значениям.

**Идея:** вместо исходных значений берутся их ранги (позиции в упорядоченном ряду), и для рангов вычисляется корреляция Пирсона.

**Формула для случая без повторяющихся рангов:**
$$
\rho = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}
$$
где $ d_i $ — разность между рангами i-го наблюдения по двум переменным, $ n $ — размер выборки.

**Интерпретация аналогична Пирсону:**
- $ \rho > 0 $ — прямая монотонная связь.
- $ \rho < 0 $ — обратная монотонная связь.
- $ \rho \approx 0 $ — монотонной связи нет.

**Преимущества перед Пирсоном:**
- Работает с **порядковыми** (ранговыми) данными (например, оценка «недоволен/нейтрально/доволен»).
- Улавливает **любые монотонные** связи, не только строго линейные (например, экспоненциальный рост).
- Устойчив к **выбросам**, так как используются ранги, а не значения.

**Пример:**
Оцениваем, связаны ли рейтинг отеля (1–5) и вероятность повторного бронирования. ρ = 0.62 → заметная монотонная связь: выше рейтинг — выше склонность к повторному обращению.

**Инсайт:** Спирмен — «страховка» от нарушений требований нормальности и линейности. Если вы не уверены в характере связи — начните со Спирмена и scatter plot.
