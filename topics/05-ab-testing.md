# 🧪 A/B-тестирование: размер выборки, длительность теста, статистическая значимость, мощность
🌐 [English version](../topics-en/05-ab-testing.md)

**A/B-тест** — это эксперимент, в котором пользователям случайно показывают два (или более) варианта продукта и сравнивают, какой из них даёт лучше результат по целевой метрике. Случайное разделение делает сравниваемые группы статистически сопоставимыми, что позволяет делать выводы о причинно-следственном эффекте изменений.

A/B-тесты — основной инструмент продуктовой аналитики и маркетинга для обоснованных решений вместо «интуиции» и «личного мнения».

## 📊 Взаимосвязь параметров

```
            ┌────────────────────────────┐
            │   Размер выборки (n)      │
            │   определяет:             │
            │   ┌────────────────────┐  │
            │   │  Длительность теста │  │
            │   └────────────────────┘  │
            │   ┌────────────────────┐  │
            │   │  Значимость (α)     │  │
            │   └────────────────────┘  │
            │   ┌────────────────────┐  │
            │   │  Мощность (1-β)     │  │
            │   └────────────────────┘  │
            └────────────────────────────┘
```

| Параметр | Что задаёт | Кто выбирает |
|----------|------------|--------------|
| Уровень значимости α | Риск ложноположительного вывода | Аналитик (обычно 5%) |
| Мощность 1-β | Шанс поймать реальный эффект | Аналитик (обычно 80%) |
| MDE (минимальный детектируемый эффект) | Какой эффект важно не пропустить | Аналитик + владелец продукта |
| Размер выборки n | Расчётный параметр | Формула из α, β, MDE |

**Ключевое правило:** нельзя «заглядывать» в данные и останавливать тест, как только p-value стал значимым, — это искажает результаты. Размер выборки и дата анализа определяются **до** запуска эксперимента.

---

## ✅ Резюме

- **Размер выборки** рассчитывается до запуска: он зависит от α, мощности и минимального эффекта, который нужно поймать.
- **Длительность теста** = время накопления нужного размера выборки с учётом календарных эффектов (недели, праздники).
- **Статистическая значимость** достигается, когда p-value < α при полной выборке.
- **Мощность** — шанс не пропустить реальный эффект; чем больше выборка, тем выше мощность.

Перед запуском любого A/B-теста обязательно рассчитайте размер выборки и зафиксируйте сроки заранее.
