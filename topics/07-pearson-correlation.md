# 📈 Коэффициент корреляции Пирсона
🌐 [English version](../topics-en/07-pearson-correlation.md)

**Коэффициент корреляции Пирсона (r)** — мера **линейной** связи между двумя количественными переменными.

**Формула:**
$$
r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}
$$

**Интерпретация:**
- $ r > 0 $ — прямая связь (рост одной переменной связан с ростом другой).
- $ r < 0 $ — обратная связь (рост одной связан с убыванием другой).
- $ r \approx 0 $ — линейной связи нет.
- $ |r| $ близок к 1 — сильная линейная связь.

| Значение | Интерпретация |
|----------|---------------|
| 0.0–0.1 | нет/очень слабая связь |
| 0.1–0.3 | слабая связь |
| 0.3–0.5 | умеренная связь |
| 0.5–0.7 | заметная связь |
| 0.7–0.9 | сильная связь |
| 0.9–1.0 | очень сильная связь |

(для модуля r; те же диапазоны с отрицательным знаком для обратной связи)

**Пример:**
Анализируем связь между spend на рекламу и выручкой за 12 месяцев. r = 0.87 → сильная прямая линейная связь: больше рекламы → больше выручки (но это не доказывает причинность!).

**Требования:**
- Переменные количественные (интервальные/отношения).
- Связь приблизительно **линейная**.
- Обе переменные приблизительно нормально распределены (при проверке значимости).
- Высокая чувствительность к **выбросам** (одна аномальная точка может сильно изменить r).

**Инсайт:** Пирсон измеряет только линейность. Если связь нелинейна (например, U-образная), r может быть близок к нулю, хотя реальная зависимость существует. В таких случаях проверяйте визуально scatter plot и используйте Спирмена.
